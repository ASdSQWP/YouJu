# CPU 与负载告警处置

## 判定标准

单台主机 CPU 使用率持续 5 分钟高于 90%，或负载超过核数的 2 倍，触发 P2 告警。

## 排查步骤

1. 先确认最近 30 分钟内是否有发布、配置变更或定时任务。
2. 用 top 或 pidstat 找出占用最高的进程，记录进程名和 PID。
3. 查看流量面板，确认是否有突发流量或异常爬虫。

## 处置措施

由发布引起的 CPU 升高，优先回滚到上一个版本。

由流量突增引起的，先扩容实例，再在网关上开启限流。

## 禁止事项

禁止在业务高峰期同时重启全部实例，必须分批重启，每批不超过 30%。

禁止直接 kill -9 数据库进程。
